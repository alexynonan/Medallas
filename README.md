# Medallas App

Medallas App es una aplicación iOS desarrollada en **SwiftUI** 
utilizando **Core Data** para persistencia local.

## Requisitos para compilar y ejecutar

Para poder compilar y ejecutar esta aplicación, necesitas:

- **Xcode** instalado (versión 15 o superior recomendada).  
- Un dispositivo o simulador con **iOS 17** o superior.  

## Cómo ejecutar la app

1. Abre **Xcode**.  
2. Abre el archivo del proyecto `Medallas.xcodeproj`
3. Selecciona un simulador o dispositivo físico.  
4. Presiona **Run** (`Cmd + R`) para compilar y ejecutar la aplicación.  

> La aplicación está lista para usar sin necesidad de instalar dependencias externas adicionales.
